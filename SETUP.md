# Convex Backend Setup Instructions

## Quick Start

1. **Install dependencies:**
   ```bash
   pnpm install
   ```

2. **Set up Convex:**
   ```bash
   pnpm convex:dev
   ```
   This will:
   - Create a new Convex project
   - Generate the `convex/_generated` directory
   - Provide you with a Convex URL

3. **Configure environment:**
   Create `.env.local` with:
   ```
   NEXT_PUBLIC_CONVEX_URL=https://your-convex-url.deployment.convex.cloud
   ```

4. **Seed the database:**
   In the Convex dashboard, run the `seedPrompts` mutation to populate with sample data.

5. **Start the development server:**
   ```bash
   pnpm dev
   ```

## File Structure

```
├─ convex/
│  ├─ schema.ts          # Database schema
│  ├─ users.ts           # User management
│  ├─ prompts.ts         # Prompt CRUD
│  ├─ votes.ts           # Voting system
│  ├─ events.ts          # Analytics tracking
│  ├─ categories.ts      # Category management
│  ├─ seed.ts            # Sample data
│  └─ _generated/        # Auto-generated by Convex
├─ app/
│  ├─ api/iphash/        # IP hashing endpoint
```
